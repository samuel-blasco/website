# Mission

Ce projet est un site personnel orienté connaissance.

Ce n'est pas un portfolio classique.

L'objectif est de créer un graphe de connaissances
interconnectant :

- Projects
- Research
- Journal
- Skills
- Collections
- Timeline
- People
- Organizations

Le contenu est stocké dans src/content.

Les pages doivent être les plus fines possibles.

Toute la logique est dans lib/.

Les composants sont atomiques.

Les types sont définis dans src/types.

Les données sont toujours typées.

Ne jamais mettre de contenu directement dans les composants.

Toujours privilégier la réutilisabilité.

Les animations utilisent Framer Motion.

Le design est minimaliste, inspiré d'Apple et Linear.
